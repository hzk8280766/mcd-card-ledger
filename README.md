# 🍔 麦卡账房 mcd-card-ledger

> **用你真实的麦当劳订单，算清麦金卡和早餐卡到底值不值得开。**
>
> 基于 [麦当劳中国 MCP](https://github.com/M-China/mcd-mcp-server) 开放能力构建的 Skill 项目，
> 参加 [WorkBuddy × 麦当劳 1024 程序员创意开发大赛](https://github.com/M-China/mcd-developer-innovation-challenge)。

「充了麦金卡，买早餐还得再开早餐卡？」
「15.8 元的早餐双月卡，到底是福利还是智商税？」

小红书上这些问题下面几百条留言，全靠个人体感猜。**麦卡账房**把这个变成一道计算题：
拉取你近 90 天的真实订单，算出你的消费画像，再对照两张卡的真实权益口径，
告诉你——**开，还是不开，几单回本，每月净省多少。**

## ✨ 它能告诉你什么

| 模块 | 输出 |
|---|---|
| 📊 消费画像 | 月均订单数、早餐订单占比、麦乐送占比、客单价、月均花费、常点 TOP3 |
| 🌅 早餐卡测算 | 按你的早餐频率 × 每单实测节省（5~8.6 元区间），算出回本所需单数、回本周期、月净收益 |
| 🃏 麦金卡测算 | 免配送费权益（月均外送单数 × 6 元）+ 套餐专享权益（保守 30% 命中率），算出月权益价值与回本周期 |
| 🎫 券资产盘点 | 未用券数量与面值、**3 天内即将过期的券**、麦麦省可领未领的券 |
| 🗣️ 账房点评 | 每句毒舌点评背后都有真实数字支撑，不是鸡汤是账本 |

所有结论附推导所需的原始数字，参数全部可在 `config.json` 调整——**不搞黑盒推荐**。

## 🚀 30 秒快速开始（无需 Token）

```bash
git clone https://github.com/<你的用户名>/mcd-card-ledger.git
cd mcd-card-ledger
python main.py --mock
```

没错，**零依赖、零配置、零 Token**（只用 Python 标准库，Python ≥ 3.9）。
`--mock` 模式内置两个典型用户画像，完整跑通全部分析与报告流程：

```bash
python main.py --mock --mock-profile commuter   # 通勤党：月均 12.7 单，早餐+外送频繁
python main.py --mock --mock-profile weekend    # 周末党：月均 4 单，两张卡都不建议开
```

## 🔌 接入你的真实数据（3 步）

**第 1 步：申请麦当劳 MCP Token**（免费）
打开 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 手机号登录 → 右上角【控制台】→【激活】→ 复制 Token。

**第 2 步：写入本地配置**

```bash
cp config.example.json config.json
# 编辑 config.json，把 mcp_token 填进去（该文件已被 .gitignore 排除，不会误提交）
```

**第 3 步：跑起来**

```bash
python main.py
```

终端会输出完整报告，并在当前目录生成 `mcd-card-report.html`——
浏览器打开就是一张**适合截图发朋友圈的卡片报告**。

## 🧮 测算口径（全部公开可调）

| 参数 | 默认值 | 依据 |
|---|---|---|
| 麦金卡月卡价格 | ¥19.9 / 30 天 | 麦当劳中国公开售价（学生学期卡另有学生价） |
| 麦金卡免配送费权益 | ¥6 / 单 | 麦乐送外送费常见水平；早餐实付满 19 / 正餐满 29 可享，每天限 2 次 |
| 麦金卡套餐专享权益 | ¥7 × 30% 命中率 | 大堡口福 5 件套专享价 = 非持卡 4 件套价格（多一份派）；保守估计仅 3 成正餐单会点专享套餐 |
| 早餐双月卡价格 | ¥15.8 / 60 天 | 支付宝入口常见活动价（官方标价 ¥19.8） |
| 早餐卡每单节省 | ¥5 ~ ¥8.6 | 27 款早餐套餐 6 折起的实测节省区间 |

以上数字均整理自 2026 年 10 月麦当劳官方渠道公开信息，**均为保守估计**；
不同城市、不同活动期可能有差异，请在 `config.json` 的 `card_params` 中按实际情况调整。

## 🔒 安全与隐私

- **只读**：仅调用 `order-list`、`query-my-coupons`、`available-coupons`、`query-my-account` 四个查询类工具，
  不创建订单、不领券、不动积分、不支付——零账户风险；
- **本地计算**：所有分析在你的电脑上完成，订单数据不出本项目进程；
- **Token 安全**：只从本地 `config.json` 或环境变量 `MCD_MCP_TOKEN` 读取，代码零硬编码。

## ❓ 常见问题

**Q：没有 Token 能玩吗？**
能，`python main.py --mock` 完整演示全流程，参数和分析逻辑与真实模式完全一致。

**Q：为什么测算结果比官方宣传省得少？**
因为本项目一律取保守口径：套餐权益只按 30% 命中率算，免配送费只按 6 元/单算。
我们宁可低估收益，也不愿给你一个"买了一定赚"的错觉。

**Q：订单字段和官方文档不一样会怎样？**
解析器对时间/金额/渠道/餐品字段都做了多候选兼容；解析不了的订单会跳过并在报告里
提示数量，不会静默算错。
